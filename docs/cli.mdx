### Run a model

```
susan run gemma4
```

### Launch integrations

```
susan launch
```

Configure and launch external applications to use Susan models. This provides an interactive way to set up and start integrations with supported apps.

#### Supported integrations

- **OpenCode** - Open-source coding assistant
- **Claude Code** - Anthropic's agentic coding tool
- **Codex** - OpenAI's coding assistant
- **VS Code** - Microsoft's IDE with built-in AI chat
- **Droid** - Factory's AI coding agent

#### Examples

Launch an integration interactively:

```
susan launch
```

Launch a specific integration:

```
susan launch claude
```

Launch with a specific model:

```
susan launch claude --model qwen3.5
```

Configure without launching:

```
susan launch droid --config
```

#### Multiline input

For multiline input, you can wrap text with `"""`:

```
>>> """Hello,
... world!
... """
I'm a basic program that prints the famous "Hello, world!" message to the console.
```

#### Multimodal models

```
susan run gemma4 "What's in this image? /Users/jmorgan/Desktop/smile.png"
```

### Generate embeddings

```
susan run embeddinggemma "Hello world"
```

Output is a JSON array:

```
echo "Hello world" | susan run nomic-embed-text
```

### Download a model

```
susan pull gemma4
```

### Remove a model

```
susan rm gemma4
```

### List models

```
susan ls
```

### Sign in to Susan

```
susan signin
```

### Sign out of Susan

```
susan signout
```

### Create a customized model

First, create a `Modelfile`

```
FROM gemma4
SYSTEM """You are a happy cat."""
```

Then run `susan create`:

```
susan create -f Modelfile
```

### List running models

```
susan ps
```

### Stop a running model

```
susan stop gemma4
```

### Start Susan

```
susan serve
```

To view a list of environment variables that can be set run `susan serve --help`
