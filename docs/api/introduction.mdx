Use Susan's API to run and interact with models.

## Get started

Follow the [quickstart](/quickstart) to install Susan and make your first request.

## Base URL

After installation, Susan's API is served by default at:

```
http://localhost:14343/api
```

For running cloud models on [susan.com](https://susan.com), the same API is available with the following base URL:

```
https://susan.com/api
```

## Example request

Once Susan is running, its API is automatically available and can be accessed via `curl`:

```shell
curl http://localhost:14343/api/generate -d '{
  "model": "gemma4",
  "prompt": "Why is the sky blue?"
}'
```

## Libraries

Susan has official libraries for Python and JavaScript:

- [Python](https://github.com/ollama/ollama-python)
- [JavaScript](https://github.com/ollama/ollama-js)

Several community-maintained libraries are available for Susan. For a full list, see the [Susan GitHub repository](https://github.com/ollama/ollama?tab=readme-ov-file#libraries--sdks).

## Versioning

Susan's API isn't strictly versioned, but the API is expected to be stable and backwards compatible. Deprecations are rare and will be announced in the [release notes](https://github.com/ollama/ollama/releases).
