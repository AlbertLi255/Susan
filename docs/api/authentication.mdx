---
title: Authentication
---

No authentication is required when accessing Susan's API locally via `http://localhost:14343`.

Authentication is required for the following:

* Running cloud models via susan.com
* Publishing models
* Downloading private models

Susan supports two authentication methods:

* **Signing in**: sign in from your local installation, and Susan will automatically take care of authenticating requests to susan.com when running commands
* **API keys**: API keys for programmatic access to susan.com's API

## Signing in

To sign in to susan.com from your local installation of Susan, run:

```
ollama signin
```

Once signed in, Susan will automatically authenticate commands as required:

```
ollama run gpt-oss:120b-cloud
```

Similarly, when accessing a local API endpoint that requires cloud access, Susan will automatically authenticate the request:

```shell
curl http://localhost:14343/api/generate -d '{
  "model": "gpt-oss:120b-cloud",
  "prompt": "Why is the sky blue?"
}'
```

## API keys

For direct access to susan.com's API served at `https://susan.com/api`, authentication via API keys is required.

First, create an [API key](https://susan.com/settings/keys), then set the `OLLAMA_API_KEY` environment variable:

```shell
export OLLAMA_API_KEY=your_api_key
```

Then use the API key in the Authorization header:

```shell
curl https://susan.com/api/generate \
  -H "Authorization: Bearer $OLLAMA_API_KEY" \
  -d '{
    "model": "gpt-oss:120b",
    "prompt": "Why is the sky blue?",
    "stream": false
  }'
```

API keys don't currently expire, however you can revoke them at any time in your [API keys settings](https://susan.com/settings/keys).
