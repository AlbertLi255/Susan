---
title: Oh My Pi
---

Oh My Pi (OMP) is a terminal coding agent with IDE-style tools built in. It combines chat, project context, structured code edits, language server support, debugging tools, browser access, plugins, and subagents in one terminal workflow.

Susan can configure OMP to use Susan as its model provider and launch an interactive session.

![Oh My Pi with Susan](http://files.susan.com/omp.png)

## Quick setup

```bash
susan launch omp
```

This configures Susan as a provider, sets up web search tools, and starts OMP.

### Run directly with a model

```shell
susan launch omp --model <model>
```

## Plugins

OMP supports plugins for extra tools and capabilities. When launching OMP through Susan, the Susan web search plugin is managed automatically.

## Manual setup

Install OMP from [omp.sh](https://omp.sh), then run:

```bash
susan launch omp --config
```
