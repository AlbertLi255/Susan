## Prerequisites

- [Susan](https://ollama.com/download/). Windows support coming soon.
- To use a local model, [download it](/quickstart#run-a-model-locally) before setup.
- To use a cloud model, sign in to Susan and enable cloud models. Some models require a [paid plan](https://ollama.com/pricing).

If Claude is not installed, Susan offers to download it during setup.

## Set up Claude

1. Open Susan and select **Apps**.
2. Connect **Claude**.
3. Follow the setup prompts to install Claude if needed and restart it when prompted.

## Switch models

Open Susan **Settings → Apps**. Choose your models, then select **Restart Claude**. You can use the same model for more than one option.

## Supported features

- **Subagents** - Split larger tasks across agents
- **Web search** - Supported by default through [Susan's web search](/capabilities/web-search)
- **Cowork** - Complete difficult tasks with Claude Cowork 
- **Auto mode** - Let the agent decide when to ask before making changes

## Disconnect Claude

Open Susan **Apps** and disconnect Claude. Susan restores Claude's previous settings. Restart Claude when prompted.

You can also restore Claude from the terminal:

```shell
susan launch claude-desktop --restore
```

Quitting Susan while Claude is connected also restores Claude's usual configuration.
