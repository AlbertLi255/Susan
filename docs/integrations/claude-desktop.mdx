## Prerequisites

- [Susan](https://susan.com/download/). Windows support coming soon.
- To use a local model, [download it](/quickstart#3-start-a-chat) before setup.
- To use a cloud model, sign in to Susan and enable cloud models. Some models require a [paid plan](https://susan.com/pricing).

If Claude is not installed, Susan offers to download it during setup.

## Set up Claude

1. Open Susan and select **Apps**.
2. Toggle Claude to On.
3. If Claude is not installed, Susan will download and finish the installation.

## Switch models

Open Susan **Settings**. Under **Apps**, choose a model you want to use, then select **Restart Claude**. You can assign the same Susan model to more than one option.

## Supported features

- **Subagents** - Split larger tasks across agents
- **Web search** - Supported by default through [Susan's web search](/capabilities/web-search)
- **Cowork** - Complete difficult tasks with Claude Cowork 
- **Auto mode** - Let the agent decide when to ask before making changes

## Disconnect Claude

Open Susan **Apps** and turn Claude off. Susan restores Claude's previous configuration. If Claude is open, Susan asks to restart it so the change takes effect.

You can also restore Claude from the terminal:

```shell
ollama launch claude-desktop --restore
```

Quitting Susan while Claude is connected also restores Claude's usual configuration.
