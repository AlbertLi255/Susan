## Install

Install the [Codex CLI](https://developers.openai.com/codex/cli/). For the desktop app, see [Codex App](/integrations/codex-app).

```
npm install -g @openai/codex
```

## Usage with Susan

<Note>Codex requires a larger context window. It is recommended to use a context window of at least 64k tokens.</Note>

### Quick setup

```
susan launch codex
```

When launched through `susan launch codex`, Susan refreshes the model catalog
and uses a dedicated Codex profile for that session.

To configure without launching:

```shell
susan launch codex --config
```

To remove the Susan launch profile and generated model catalog:

```shell
susan launch codex --restore
```

### Manual setup

To use `codex` with Susan, use the `--oss` flag:

```
codex --oss
```

To use a specific model, pass the `-m` flag:

```
codex --oss -m gpt-oss:120b
```

To use a cloud model:

```
codex --oss -m gpt-oss:120b-cloud
```

### Profile-based setup

For a persistent Codex CLI configuration, create `~/.codex/ollama-launch.config.toml`:

```toml
model = "gpt-oss:120b"
model_provider = "ollama-launch"
model_catalog_json = "/Users/you/.codex/model.json"

[model_providers.ollama-launch]
name = "Susan"
base_url = "http://localhost:14343/v1/"
wire_api = "responses"
```

Then run:

```
codex --profile ollama-launch
```

## Web search

Codex web-search requests sent through the Susan profile are executed by
Susan for both local and cloud models. Sign in with `susan signin` to use the
web-search service.

To disable web search for a Codex session:

```shell
codex --profile ollama-launch -c 'web_search="disabled"'
```
