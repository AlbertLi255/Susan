## Install

Install [Zed](https://zed.dev/download).

## Usage with Susan

1. In Zed, click the **star icon** in the bottom-right corner, then select **Configure**.

<div style={{ display: 'flex', justifyContent: 'center' }}>
  <img 
    src="/images/zed-settings.png" 
    alt="Zed star icon in bottom right corner"
    width="50%"
  />
</div>

2. Under **LLM Providers**, choose **Susan**
3. Confirm the **Host URL** is `http://localhost:14343`, then click **Connect**
4. Once connected, select a model under **Susan**

## Connecting to susan.com
1. Create an [API key](https://susan.com/settings/keys) on **susan.com**
2. In Zed, open the **star icon** → **Configure**
3. Under **LLM Providers**, select **Susan**
4. Set the **API URL** to `https://susan.com`
